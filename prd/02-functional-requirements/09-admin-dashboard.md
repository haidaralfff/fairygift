# 4.9 Admin Dashboard

**Deskripsi:**

Admin Dashboard merupakan halaman khusus untuk mengelola seluruh aktivitas operasional FairyGift.

## A. Dashboard Overview

**Kebutuhan Fungsional:**
- Menampilkan jumlah pesanan.
- Menampilkan pesanan terbaru.
- Menampilkan ringkasan status pesanan.
- Menampilkan jumlah pembayaran yang belum diverifikasi.

## B. Order Management

**Kebutuhan Fungsional:**
- Menampilkan seluruh pesanan pelanggan.
- Melihat detail produk dan kustomisasi.
- Melihat pesan pada kartu ucapan.
- Melihat informasi pelanggan.
- Melihat informasi pengiriman atau pengambilan.
- Memperbarui status pemrosesan pesanan.

## C. Payment Management

**Kebutuhan Fungsional:**
- Melihat daftar pembayaran yang belum dikonfirmasi.
- Memeriksa informasi pembayaran melalui komunikasi dengan pelanggan di WhatsApp.
- Memperbarui status pembayaran secara manual.
- Melihat riwayat perubahan status pembayaran.

## D. Product Management

**Kebutuhan Fungsional:**
- Menambahkan produk.
- Mengubah informasi produk.
- Menghapus produk.
- Mengatur harga produk.
- Mengelola gambar produk.
- Mengatur ketersediaan produk.

## E. Customization Management

**Kebutuhan Fungsional:**
- Mengelola jenis kemasan.
- Mengelola warna kemasan.
- Mengelola komponen isi hadiah.
- Mengatur harga setiap komponen.
- Mengelola desain kartu ucapan.
- Mengatur ketersediaan komponen.

**Acceptance Criteria:**

- Admin dapat mengakses dashboard melalui autentikasi.
- Admin dapat melihat detail pesanan secara lengkap.
- Admin dapat memperbarui status pesanan.
- Admin dapat memverifikasi pembayaran secara manual.
- Perubahan katalog dan harga tersimpan di sistem.
