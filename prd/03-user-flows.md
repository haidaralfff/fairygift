# 5. USER FLOW

## 5.1 Customer Flow

1. Pelanggan membuka website FairyGift.
2. Pelanggan melihat homepage.
3. Pelanggan memilih paket hadiah atau Custom Gift Builder.
4. Jika memilih Custom Gift Builder, pelanggan menentukan kemasan, isi hadiah, dan kartu ucapan.
5. Sistem menghitung total harga secara otomatis.
6. Pelanggan menambahkan produk ke keranjang.
7. Pelanggan memeriksa ringkasan pesanan.
8. Pelanggan mengisi informasi checkout.
9. Pelanggan mengonfirmasi pesanan.
10. Sistem menyimpan pesanan dan menghasilkan nomor pesanan.
11. Sistem menampilkan halaman konfirmasi pesanan.
12. Pelanggan menekan tombol Hubungi Admin via WhatsApp.
13. WhatsApp terbuka dengan pesan otomatis berisi detail pesanan.
14. Pelanggan mengirim pesan kepada admin.
15. Admin memberikan instruksi pembayaran melalui WhatsApp.
16. Pelanggan melakukan pembayaran dan mengirimkan konfirmasi kepada admin melalui WhatsApp.

## 5.2 Admin Flow

1. Admin membuka halaman login.
2. Admin memasukkan kredensial.
3. Sistem memvalidasi autentikasi.
4. Admin masuk ke dashboard.
5. Admin melihat daftar pesanan.
6. Admin memeriksa detail pesanan dan kustomisasi.
7. Admin menerima komunikasi pelanggan melalui WhatsApp.
8. Admin memberikan instruksi pembayaran.
9. Admin memeriksa konfirmasi atau bukti pembayaran dari pelanggan.
10. Admin memperbarui status pembayaran melalui dashboard.
11. Admin memproses pesanan sesuai detail yang telah dikonfirmasi.
12. Admin memperbarui status pemrosesan pesanan hingga selesai.
